# StackPass

StackPass is a GitHub-powered developer profile platform with wallet passes. Enter Sprints and Seasons to win prizes and badges.

## Features

### Core Platform
- **Developer Profiles** - GitHub-powered cards with stats, repos, and custom projects
- **Wallet Passes** - Add your profile to Apple Wallet / Google Wallet
- **Developer Network** - Connect with other developers, send connection requests
- **Achievement System** - Earn 39 unique badges across 8 categories

### Hackathons System (Pro Feature)
- **Registration Phase** - Pre-register with capacity limits
- **Team Formation** - Form teams up to 5 members, send/accept invites
- **Project Submissions** - Submit GitHub projects with demos and videos
- **Community Voting** - Pro members vote on submissions
- **Winners & Prizes** - Top 3 winners receive cash prizes and exclusive badges
- **Email Notifications** - Confirmations, team invites, winner announcements

### Admin Dashboard
- Create and manage hackathons
- Monitor registrations and submissions
- Declare winners with automated badge creation
- Platform analytics and settings

## Getting Started

1. Clone the repo
2. Run `pnpm install`
3. Run `pnpm dev`
